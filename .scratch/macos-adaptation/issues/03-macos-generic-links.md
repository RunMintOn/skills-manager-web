# 03: Mac 通用链接工作区

**What to build:** 用户可以扫描 Mac 目录，预检、创建和删除本地文件或目录符号链接。删除操作只删除链接入口，不删除目标。

**Blocked by:** 01: Mac 基础运行与内置 Agent 路径

**Status:** done

- [x] Mac 工作区保留通用链接入口，并复用现有工作台。
- [x] 用户可以扫描指定目录的直接子项或递归树。
- [x] 扫描结果区分文件、目录、符号链接和断链。
- [x] 创建前检查目标存在、链接路径不存在、父目录可用和路径安全。
- [x] 用户确认后可以创建文件和目录符号链接。
- [x] 删除只接受识别出的符号链接，不删除普通文件、目录或链接目标。
- [x] 空格、Unicode 和 shell 特殊字符路径保持安全。

实现约束：

- 复用现有通用链接工作台和预检接口。
- Mac 只使用当前机器上的绝对 POSIX 路径。
- 使用 `fs.promises.symlink`、`lstat` 和 `unlink` 等本地 Node 文件系统操作，不调用 shell 命令。
- 不增加跨环境链接，不修改旧 WSL/Windows 链接策略。
- 新增测试放入 `npm run test:macos`，不得调用 `powershell.exe`、`wsl.exe` 或 Windows Junction。
